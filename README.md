# IP-finder

IP-finder собирает IP-адреса из открытых источников и сохраняет результат в обычный
текстовый файл. Проект работает без Docker и базы данных: достаточно Linux,
Python 3.10+ и доступа в интернет.

Поддерживаются три независимых режима:

- **по стране:** RIPEstat → сетевые префиксы → IP-адреса;
- **по ASN:** RIPEstat → анонсированные префиксы автономной системы → IP-адреса;
- **по домену:** Certificate Transparency (Cert Spotter) → доменные имена → IPv4 и, по запросу, IPv6.

> [!IMPORTANT]
> Код страны, запись в CT-журнале или найденный IP не подтверждают право проверять,
> сканировать или атаковать соответствующий ресурс. Используйте инструмент только
> для собственных систем либо при наличии явного разрешения владельца.

## Возможности

- Потоковая обработка крупных диапазонов без загрузки всех адресов в память.
- Быстрое возобновление поиска по стране или ASN с последнего записанного адреса.
- Ограничение числа адресов в целом и отдельно для каждого префикса.
- Параллельное DNS-разрешение в CT-режиме с ограниченным числом задач.
- Постраничная загрузка CT-данных с управляемым лимитом запросов.
- Локальный кэш ответов источников сроком на 7 дней.
- Настраиваемые каталоги результатов и служебных данных.
- Единое меню `init.sh` и пять небольших shell-команд.

## Требования

- Linux;
- Python 3.10 или новее (проверено на Python 3.14);
- Bash;
- доступ к `stat.ripe.net` и `api.certspotter.com`.

Системная база данных, Docker и дополнительные системные пакеты не нужны.

## Быстрый старт

Из корня проекта:

```bash
./init.sh
```

Для первого запуска выберите установку зависимостей, затем проверку окружения. Эти
два пункта можно выполнить одной командой:

```bash
./init.sh 1 2
```

Пункты 3 и 4 запускают поиск по стране/ASN и домену. Перед запуском меню
предложит ввести аргументы по одному: отдельной строкой цель (`DE` или
`--ct`, затем `example.org`), затем нужные флаги и значения. Введите **`0`**
отдельной строкой, чтобы завершить ввод: ноль не передаётся скрипту. Если сразу
ввести `0`, запустится демонстрационный поиск без сохранения результата.

Например, после `./init.sh 3` можно ввести последовательно `DE`, `--per-prefix`,
`5`, `--max-addresses`, `100`, `0`. Для пути с пробелами введите `--out`, а затем
весь путь одной строкой без кавычек. Чтобы передать настоящее нулевое значение
флага, используйте форму `--limit=0`.

Каждую команду также можно вызывать напрямую:

```bash
bash scripts/40_run_country.sh
bash scripts/50_run_ct.sh
```

При прямом запуске без аргументов в терминале скрипты поиска задают те же вопросы.
Если ввод не интерактивный, оба сценария сохраняют небольшие демонстрационные
настройки. При прямом запуске с аргументами вопросы не задаются.

## Использование

### Поиск по стране

Передайте двухбуквенный код страны:

```bash
bash scripts/40_run_country.sh DE \
  --no-ipv6 \
  --per-prefix 10 \
  --max-addresses 5000 \
  --out out/de.txt
```

RIPEstat возвращает как отдельные, так и вложенные сети. Перед обходом полностью
вложенные сети отбрасываются, чтобы один адрес не попадал в результат повторно.
Соседние сети не объединяются: `--per-prefix` применяется к каждому исходному
префиксу отдельно.

Поиск по стране сохраняет курсор. Если прогон прервать, следующий запуск с той же
страной, настройками и снимком сетей продолжится после последнего адреса,
гарантированно записанного на диск. Изменение настроек или списка сетей начинает
отдельную выборку. Даже внутри большой сети переход к курсору не перебирает
предыдущие адреса.

> [!WARNING]
> Без `--per-prefix` и `--max-addresses` программа разворачивает весь доступный
> диапазон IPv4. Это может означать десятки миллионов строк. Для первого запуска
> всегда задавайте лимиты. IPv6 целиком не разворачивается: без явного лимита
> выбирается не более 32 адресов из каждого IPv6-префикса.

### Поиск по ASN

Тот же маршрут работает с анонсированными префиксами автономной системы:

```bash
bash scripts/40_run_country.sh --asn AS3333 \
  --no-ipv6 \
  --per-prefix 10 \
  --max-addresses 1000
```

ASN можно записать и без `AS`. Курсор, лимиты и формат результата такие же, как
при поиске по стране. Источником служит RIPEstat Announced Prefixes.

### Поиск по домену

```bash
bash scripts/50_run_ct.sh \
  --ct example.org \
  --ct-pages 3 \
  --workers 8 \
  --max-addresses 200 \
  --out out/example.txt
```

Cert Spotter возвращает имена из публичных CT-журналов, включая поддомены. Записи
могут быть историческими или устаревшими; в результат попадут только имена, которые
на момент запуска разрешаются в IPv4. Флаг `--include-ipv6` добавляет AAAA-записи.

В этом режиме `--max-addresses` ограничивает количество обрабатываемых **имён**,
а не число итоговых IP-адресов. Одно имя может разрешиться в несколько адресов.
`--ct-pages` задаёт число страниц Cert Spotter (по умолчанию одну, максимум 10):
одна страница может содержать не все сертификаты домена. Каждый дополнительный
запрос расходует лимит API. `--workers` управляет числом параллельных DNS-запросов
(по умолчанию 8, максимум 32). Результат записывается постепенно, без накопления
всех пар «адрес—имя» в памяти.

### Прямой запуск Python

Точка входа должна запускаться как модуль из корня проекта:

```bash
.venv/bin/python -m src.main LI --per-prefix 5 --max-addresses 100
.venv/bin/python -m src.main --asn AS3333 --per-prefix 5 --max-addresses 100
.venv/bin/python -m src.main --ct example.org --max-addresses 200
```

Запуск `python src/main.py` не поддерживается, поскольку импорты рассчитаны на пакет
`src` в корне проекта.

## Параметры командной строки

Общие параметры:

| Параметр | Назначение |
| --- | --- |
| `--limit N` | Показать в терминале не более `N` строк; по умолчанию 200. |
| `--max-addresses N` | Остановить обработку после `N` адресов; в CT-режиме — после `N` имён. |
| `--out ФАЙЛ` | Записать результат в указанный файл; существующий файл защищён от случайной замены. |
| `--append` | Дописать результат, не заменяя существующий файл. |
| `--force` | Разрешить замену существующего файла, указанного через `--out`. |
| `--no-save` | Не записывать результат и не менять курсор; кэш источников остаётся включённым. |
| `--no-cache` | Не читать и не записывать кэш ответов источников. |

Только для поиска по стране или ASN:

| Параметр | Назначение |
| --- | --- |
| `--per-prefix N` | Взять до `N` адресов из каждого префикса; `0` означает все IPv4. |
| `--no-ipv6` | Исключить IPv6-префиксы. |
| `--restart` | Игнорировать сохранённый курсор и начать сначала. |
| `--asn AS123` | Получить анонсированные префиксы автономной системы вместо страны. |

Только для поиска по домену:

| Параметр | Назначение |
| --- | --- |
| `--ct ДОМЕН` | Включить CT-режим для домена и его поддоменов. |
| `--ct-pages N` | Загрузить до `N` страниц Cert Spotter; по умолчанию 1, максимум 10. |
| `--workers N` | Одновременно разрешать до `N` имён через DNS; по умолчанию 8. |
| `--include-ipv6` | Добавить IPv6-адреса из AAAA-записей. |

Нужно выбрать ровно одну цель: код страны, `--asn` или `--ct`. Отрицательные лимиты
и несовместимые сочетания параметров отклоняются до обращения к источникам.

## Результаты и служебные данные

По умолчанию каждый прогон создаёт отдельный файл
`out/<маршрут>_<дата-время>.txt`. Полный путь печатается в конце работы после
`# файл:`. Имя также содержит доли секунды, чтобы соседние запуски не совпали.
Если путь указан через `--out` и уже существует, используйте `--append` для
дозаписи или `--force` для замены.

Формат результата зависит от режима:

```text
# страна: один адрес в строке
5.34.248.1

# CT: адрес, табуляция, имя
104.20.26.136	example.org
```

Рабочие каталоги:

- `out/` — результаты;
- `data/cache/` — ответы источников и время их получения;
- `data/state/` — курсоры поиска по стране.

Каталоги создаются автоматически. Их можно переопределить переменными окружения
`IPFINDER_OUT` и `IPFINDER_DATA` либо необязательным файлом `.env`:

```bash
cp .env.example .env
```

Удаление `data/` сбрасывает кэш и курсоры; результаты в `out/` при этом не меняются.

Чтобы дописывать несколько запусков в один файл:

```bash
bash scripts/40_run_country.sh LI --out out/all-addresses.txt --append
```

## Скрипты

`init.sh` строит компактное меню из пяти файлов в `scripts/`. Порядок и подписи
берутся из строк `ORDER` и `DESC` в начале каждого файла. При запуске пунктов 3
и 4 аргументы запрашиваются перед каждым скриптом; `0` завершает ввод.

| Скрипт | Назначение |
| --- | --- |
| `init.sh` | Показать меню или выполнить пункты, переданные номерами. |
| `scripts/10_install.sh` | Создать `.venv` и установить зависимости. |
| `scripts/30_check.sh` | Проверить Python, окружение, каталоги и доступность источников. |
| `scripts/40_run_country.sh` | Запустить поиск по стране или ASN. |
| `scripts/50_run_ct.sh` | Запустить поиск по домену. |
| `scripts/60_test.sh` | Выполнить тесты. |

## Тесты

```bash
bash scripts/60_test.sh
```

Тесты проверяют разбор ответов источников, обработку крупных диапазонов
без материализации, возобновление по курсору, фильтрацию вложенных сетей, CT-пагинацию,
ASN-маршрут, DNS-разрешение, сохранение файлов и кэш. Тестам не нужны сеть или база данных: внешние зависимости заменены
моками и временными каталогами.

## Решение проблем

- **`нет venv`** — выполните `bash scripts/10_install.sh`.
- **`источник не ответил`** — проверьте сеть и повторите позже. Успешно полученные
  ответы уже находятся в кэше; временные и ошибочные ответы туда не записываются.
- **Прогон кажется зависшим** — вероятно, обрабатывается большой диапазон без лимита.
  Прервите процесс с помощью `Ctrl+C`, добавьте `--per-prefix` или
  `--max-addresses` и повторите запуск. Файл и курсор останутся согласованными.
- **Результат пустой** — источник мог не вернуть сети или CT-имена, либо найденные
  имена не разрешились в IPv4. Сводка с количеством объектов выводится в stderr.
- **Cert Spotter отвечает `429`** — исчерпан лимит публичного API. Дождитесь нового
  окна запросов и повторите запуск.
